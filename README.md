# 🧰 Каталог инструментов и материалов

Личная опись домашних инструментов, электрики, сантехники, крепежа и фурнитуры.

## Открыть каталог

Онлайн: **https://muninser-star.github.io/tools-catalog/**

Локально: откройте **[каталог.html](каталог.html)** в браузере (двойной клик).
Фотографии лежат рядом в папке `img/` и подгружаются по мере прокрутки, поэтому
html-файл нужно держать вместе с этой папкой (скачивать репозиторий целиком, а не один файл).

## Возможности

- Категории (несколько на позицию), фильтр и поиск
- Превью фото → клик открывает во весь экран
- Текстовое описание каждой позиции
- Поле «место хранения» — редактируется прямо в карточке
- Кнопка **＋ Добавить** — свои фото и описания
- **⭳ Бэкап / ⭱ Импорт** правок в JSON

Правки (места хранения, новые фото, описания) сохраняются в localStorage браузера.
Периодически делайте **⭳ Бэкап**, чтобы не потерять их.

## Файлы

- `каталог.html` / `index.html` — сам каталог (одинаковые файлы, ~95 КБ)
- `img/i*.jpg` — фотографии позиций, подключены к каталогу и грузятся лениво
- `photo_*.jpg`, `photo_*.webp` — исходные фотографии (оригиналы)
