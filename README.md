# 🧰 Каталог инструментов и материалов

Личная опись домашних инструментов, электрики, сантехники, крепежа и фурнитуры.

## Открыть каталог

Скачайте и откройте **[каталог.html](каталог.html)** в браузере (двойной клик).
Все 16 фотографий вшиты внутрь файла — он самодостаточен, отдельные `.jpg` для просмотра не нужны.

## Возможности

- Категории (несколько на позицию), фильтр и поиск
- Превью фото → клик открывает во весь экран
- Текстовое описание каждой позиции
- Поле «место хранения» — редактируется прямо в карточке
- Кнопка **＋ Добавить** — свои фото и описания
- **⭳ Бэкап / ⭱ Импорт** правок в JSON

Правки (места хранения, новые фото, описания) сохраняются в localStorage браузера.
Периодически делайте **⭳ Бэкап**, чтобы не потерять их.

## Файлы

- `каталог.html` — сам каталог со встроенными фото
- `photo_*.jpg` — исходные фотографии (оригиналы)
